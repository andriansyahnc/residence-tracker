# Docs

Product and engineering documents for this workshop project live here.

| Folder | Purpose | When to write |
|--------|---------|---------------|
| [`prd/`](prd/) | Product Requirements Documents — problem, users, scope, requirements, edge cases, success metrics | Before building a product or major feature |
| [`rfc/`](rfc/) | Requests for Comments — proposed designs for review | Before a non-trivial technical or product design change |
| [`adr/`](adr/) | Architecture Decision Records — decisions already made | When a choice is locked and future readers need context |

## Conventions

- Prefer short, dated, single-topic docs over long living wikis.
- Link PRD → RFC → ADR when a requirement becomes a design and then a decision.
- Do not put secrets or credentials in this tree.
